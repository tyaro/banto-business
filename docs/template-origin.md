# テンプレート派生元とマージ判断の記録

---

## なぜこのファイルが必要か

Banto への**パッケージ依存**は git タグで固定でき、更新は明示的な操作になる。

一方、テンプレートから派生した**ボイラープレート**（Tauri設定 / CI定義 / ディレクトリ構成 / ビルドスクリプト / lint設定等）は、派生した瞬間から独立したコピーになり、Banto 側の改善が自動では反映されない。

放置すると `banto-industrial` と `banto-business` の2つの派生先で構成が徐々に乖離し、「Banto の標準構成」が実質的に存在しなくなる。

**全面同期は行わない。** Banto 側テンプレート更新時に差分を確認し、選択的に取り込み、判断をここに記録する。

## 更新手順

Banto 側テンプレートが更新された場合：

```
1. Banto の該当タグ間の差分を確認
   git -C ../banto diff <前回タグ>..<新タグ> -- <テンプレート由来パス>

2. 変更を3分類する
   - 取り込む       … バグ修正・セキュリティ・共通基盤の改善
   - 見送る         … Industrial固有 / Businessに不要 / 改変済みで競合
   - 保留           … 判断に時間が必要

3. 取り込む変更を手動適用

4. ビルド・テスト・アプリ起動を確認

5. 下の「マージ判断ログ」に記録

6. 「現在の派生状態」の最終マージ確認日・タグを更新
```

**「とりあえず全部取り込む」をしない。** 改変済みファイルへの機械的な適用は、アプリ名変更等の派生時カスタマイズを壊す。
