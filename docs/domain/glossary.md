# 用語集

Banto Business のドメイン用語。**画面・コード・ドキュメントで表記を統一する。**

---

## エンティティ

| 用語       | 英語 / 識別子     | 定義                                                            |
| ---------- | ----------------- | --------------------------------------------------------------- |
| 顧客       | Customer          | 請求先となる取引先。締日・支払条件を保持する                    |
| 案件       | Project           | 管理の中心単位。顧客に属し、工数・経費・請求が紐づく            |
| 工数       | WorkLog           | 案件に対する作業時間の記録。1行が「ある日・ある作業分類の作業」 |
| 出張       | Trip              | 案件に関連する出張のまとまり。WorkLog と Expense を一括生成する |
| 経費       | Expense           | 案件の直接経費。仕入側の税区分を保持する                        |
| 請求書     | Invoice           | 顧客へ発行する適格請求書。複数案件の明細を含みうる              |
| 請求明細   | InvoiceLine       | 請求書の1行。どの案件の売上かを `project_id` で保持する         |
| 入金       | Payment           | 顧客からの入金1件。どの請求書への充当かは持たない               |
| 消込       | PaymentAllocation | 入金を請求書へ充当した記録。差額理由コードを持つ                |
| 原価レート | CostRate          | 作業分類ごとの内部時間単価のマスタ                              |

---

## 金額・計算

| 用語                           | 定義                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **適用単価**（`applied_rate`） | WorkLog 記録時点の内部時間単価を行に焼き付けた値。マスタを後から変えても遡って変わらない    |
| **内部原価**                   | `floor(作業分 × 適用単価 ÷ 60)`。WorkLog 1行ごとに円で確定する                              |
| **工数原価**                   | 案件に属する WorkLog の内部原価の合計（丸め済みの行原価を合計する）                         |
| **直接経費**                   | 案件に属する Expense の金額合計                                                             |
| **案件売上**                   | その案件を参照する**確定済** InvoiceLine の税抜金額合計。未請求の作業・経費は売上に立たない |
| **案件粗利**                   | `案件売上 − 工数原価 − 直接経費`                                                            |
| **粗利率**                     | `案件粗利 ÷ 案件売上`。売上が 0 の場合は算出しない（表示は「—」）                           |
| **実質時間単価（移動込み）**   | `案件粗利 ÷ 全 WorkLog 時間`                                                                |
| **実質時間単価（移動除く）**   | `案件粗利 ÷ 作業分類「移動」を除く WorkLog 時間`。移動込みと**必ず併記する**                |
| **請求進捗**                   | `案件売上 ÷ 契約額`。進行中案件で粗利がマイナスに見える場合の判断材料                       |
| **残額**                       | `請求額 − 充当額合計`。0 未満にはしない                                                     |
| **Overdue（期限超過）**        | 状態ではなく導出値。`支払期限 < 今日 AND 残額 > 0 AND 状態 ≠ Cancelled`                     |

**金額は全て INTEGER（円）。** 率は basis point（1/10000）または分子分母で保持する。

## 税

| 用語     | 識別子         | 定義                                                                               |
| -------- | -------------- | ---------------------------------------------------------------------------------- |
| 標準税率 | `STANDARD_10`  | 10%。開発費・設計費・交通費・宿泊費・部材費など大半がこれ                          |
| 軽減税率 | `REDUCED_8`    | 8%。飲食料品等。現状は発生しない前提だが実装は保持する                             |
| 非課税   | `EXEMPT`       | 消費税の性質上または政策上課税しないもの。**印紙税・行政手数料・保険料・住宅家賃** |
| 不課税   | `OUT_OF_SCOPE` | そもそも課税対象外の取引。**国際線運賃・海外での支出・慶弔費・給与・保険金の受取** |

> `EXEMPT` と `OUT_OF_SCOPE` はどちらも消費税額 0 だが、仕入税額控除の集計上は区別が必要なため、コード値を分けて保持する。

| 用語                       | 定義                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| **税率区分ごとの端数処理** | 1つの適格請求書につき、税率ごとに1回だけ端数処理する。明細行ごとには行わない                  |
| **端数処理方向**           | 既定は切捨て（1円未満）。設定で四捨五入・切上げも選べる。Invoice 確定時にスナップショットする |
| **ゼロ方向**               | マイナス金額の端数処理の向き。`−3,333.5 → −3,333`（`−3,334` ではない）                        |
| **登録番号**               | 適格請求書発行事業者の `T` + 13桁。settings に保持し、Invoice 確定時にスナップショットする    |

## 状態

| 用語     | 識別子          | 定義                                                                                |
| -------- | --------------- | ----------------------------------------------------------------------------------- |
| 下書き   | `Draft`         | 編集可能。請求書番号は未採番                                                        |
| 発行済   | `Issued`        | 確定・採番済み。明細は編集不可                                                      |
| 一部入金 | `PartiallyPaid` | 残額 > 0 かつ充当額 > 0                                                             |
| 入金済   | `Paid`          | 残額 0                                                                              |
| 取消     | `Cancelled`     | 赤伝。訂正時は取消した上で新しい請求書を発行し、`corrected_invoice_id` で対応付ける |

> `Waiting Payment` は使わない（`Issued` に統合）。`Overdue` は状態として持たない。

### 案件の状態

`見込 / 受注 / 進行中 / 検収待ち / 完了 / 失注 / 保留`

- 採算集計の対象は**失注を除く全状態**
- ダッシュボードの「進行中案件」は `受注 / 進行中 / 検収待ち`

## 差額理由コード（消込）

| コード         | 意味                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| `TRANSFER_FEE` | 振込手数料の先方差引                                                       |
| `WITHHOLDING`  | 源泉徴収（自分からは請求書に記載しないが、先方が差し引いてきた場合に使う） |
| `DISCOUNT`     | 値引き                                                                     |
| `OVERPAYMENT`  | 過入金                                                                     |
| `OTHER`        | その他（備考必須）                                                         |

---

## 作業分類（WorkLog）

`設計 / PLC開発 / SCADA開発 / PCアプリ開発 / テスト / 社内調整 / 現地作業 / 移動 / 打合せ / その他`

- **「移動」は実質時間単価の分母から除外する系統を持つ**ため、コード値で扱う（文字列比較でハードコードしない）
- 作業分類ごとに内部原価レートを設定する

## 経費分類（Expense）

`交通費 / 宿泊費 / 送料 / 部材費 / 消耗品 / 外注費 / その他`

## 区別が必要な似た用語

| 用語           | 用語           | 違い                                                                                         |
| -------------- | -------------- | -------------------------------------------------------------------------------------------- |
| 契約額         | 案件売上       | 契約額は受注時点の金額。案件売上は実際に請求した金額（確定済 InvoiceLine の合計）            |
| 請求額         | 入金額         | 請求額は Invoice の合計。入金額は実際に振り込まれた金額（充当前）                            |
| 充当額         | 入金額         | 充当額は特定の請求書に割り当てた金額。1件の入金が複数請求書に分かれることがある              |
| `billable`     | `invoiced`     | `billable` は顧客請求対象かどうか。`invoiced` は既に請求書に載せたかどうか。**別フラグ**     |
| 仕入側の税区分 | 請求側の税区分 | Expense が持つのは仕入側（国際線＝不課税など）。顧客への請求は一律 10%（役務の対価に含める） |
